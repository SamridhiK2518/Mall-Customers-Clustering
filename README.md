# Mall Customer Segmentation using K-Means

This project uses **K-Means Clustering** to segment mall customers based on their **Age, Annual Income, and Spending Score**.

The project includes:

* Data preprocessing and feature selection
* Feature scaling using StandardScaler
* Elbow Method to determine the number of clusters
* K-Means clustering
* 2D and 3D cluster visualization
* Cluster-wise customer analysis and business insights
* Export of the segmented customer dataset

The goal is to identify distinct customer groups and understand their spending patterns for targeted marketing and customer engagement.
